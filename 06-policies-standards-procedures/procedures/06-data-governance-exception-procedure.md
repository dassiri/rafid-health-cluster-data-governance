## 1. Purpose

Handle **exceptions to POL-001** (and to Standards where they instantiate Policy) without silent local practice `[B]`.

**DMC remains Accountable** for governance exceptions (Phase 3–4). CDO **recommends**. Time-boxed waivers **inside** an already approved Policy envelope: CDO **A**, DMC **I** at next meeting (Phase 3). If the request is **outside** Policy, this procedure applies and **DMC = A**.

## 2. Process

```text
Request → Justification → DMO review → DMC approval/denial → Register → Monitor → Close/Renew
```

| Step | Who | Action |
| --- | --- | --- |
| **Request** | Requestor + Data Owner (or CDO if Owner is the issue) | Governance Exception Request |
| **Justification** | Requestor | Risk, duration, compensating control, classification of data involved |
| **DMO review** | DMO / CDO | Completeness; PDPO **C** if personal; Legal **C** if legal risk; not a substitute DMC vote |
| **DMC approval/denial** | DMC **A**; CEO chairs `[B]` | Approve, deny, or approve time-boxed |
| **Register** | DMO | Policy Exception Register |
| **Monitor** | Steward / DMO | Compensating controls still in place |
| **Close/Renew** | DMC **A** to renew; DMO closes when expired and not renewed | Change Record / register status |

## 3. What is not an exception under this procedure

- In-policy access/share → PRC-005  
- Classification change → PRC-002 (Owner **A**)  
- Quality residual accepted by Owner **within** Policy → PRC-003  

## 4. Evidence

Exception Request; DMC decision; register entry; expiry. No numeric SLA.
