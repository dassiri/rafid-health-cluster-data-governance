---

## 2. Principles (locked)

| Principle | Intent | Label |
| --- | --- | --- |
| **Purpose-driven retention** | Keep data for an identified business, record, legal, or privacy-related purpose — not “because we might need it” | `[A][B]` |
| **Minimum necessary retention** | Do not keep longer than the approved rule requires **once that rule is verified** | `[A][B]` |
| **Classification-aware handling** | Tier influences how data is accessed, shared, stored, transmitted, monitored, and disposed | `[A][B]` |
| **Owner accountability** | Data Owner **A** for domain lifecycle decisions (Phase 4) | `[A][B]` |
| **Legal / regulatory hold** | An active hold **suspends** normal disposal | `[A][B]` |
| **Controlled archival** | Archive is a governed state, not a forgotten share drive | `[A][B]` |
| **Secure disposition** | Disposal is authorized and appropriate to classification and media — methods conceptual only | `[A][B]` |
| **Traceability** | Lifecycle status and holds are visible in governed records | `[A][B]` |
| **Evidence of disposition** | Disposal is closed only with a Disposal Record | `[A][B]` |
| **No indefinite retention by default** | “Keep forever” is not the default. Indefinite keep requires an **approved** rule or hold — not silence | `[A][B]` |

None of these principles is a numeric period. Verified requirements remain `[NDMO verification required]` / `[Legal / regulatory verification required]`.
