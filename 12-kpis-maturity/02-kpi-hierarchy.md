## 2. Locked hierarchy

```text
Strategic Objective
→ Governance Outcome
→ KPI
→ Metric Definition
→ Evidence Source
→ Reporting
→ Decision/Action
```

| Layer | Meaning | Example (illustrative only) `[A]` |
| --- | --- | --- |
| **Strategic Objective** | Phase 1 G-O statement | G-O1 Establish authority for data |
| **Governance Outcome** | Observable control state | Every in-scope domain has exactly one Data Owner |
| **KPI** | Named indicator with Rafid ID | DG-KPI-001 Data Owner Assignment Coverage |
| **Metric Definition** | Numerator / denominator / unit | Assigned Owner titles ÷ 8 domains |
| **Evidence Source** | Register or record (not claimed live) | Ownership Registry |
| **Reporting** | Phase 3 forum and pack | DMC quarterly KPI pack |
| **Decision/Action** | What the number is **for** | Escalate vacant Owner under existing Phase 3/4 path — **no new A** |

A KPI without a Decision/Action path is a vanity candidate and must not enter the executive set.
