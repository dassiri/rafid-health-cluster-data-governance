## 3. Method `[A][B]`

```text
Define KPI
→ Identify evidence source
→ Measure baseline (when data exist)
→ Propose target
→ Owner acceptance for domain KPIs
→ Record on Definition Sheet
→ Review with the KPI (Phase 3 forums)
```

| Step | Rule |
| --- | --- |
| Baseline | First measured occupancy/rate using the Definition Sheet. Until then, Target Status remains the locked sentence in §2 |
| Illustrative example | If a number is shown for teaching, label **`[A] Illustrative Rafid target`**. It is **not** a live target and **not** NDMO-mandated |
| Phase 7 overlap | Quality Target / Warning / Breach examples already in Phase 7 stay **`[A] Illustrative Rafid target`**. This phase does not convert them into claimed Rafid performance |
| Forbidden | Copying “industry 95%” as a Rafid target without baseline; inventing retention-period compliance targets |

DMC: Governance escalation and decisions within the approved Phase 3 governance authority and decision-right framework. **No new DMC decision right.** DMC is not the routine setter of every operational target.
