## 2. Locked chain

```text
Proposed
→ Defined
→ Validated
→ Approved under existing authority
→ Implemented
→ Reviewed
→ Retired
```

| Step | Activity | Who |
| --- | --- | --- |
| Proposed | Need, vanity test, outcome link | Requestor + DMO |
| Defined | Full catalogue fields | DMO; Business Data Steward **R** for occupancy test |
| Validated | Evidence source exists; formula does not redesign Phases 4–11; ID is Rafid `DG-KPI-nnn` not an NDMO ID | DMO; Data Owner **C** if domain KPI |
| Approved under existing authority | Catalogue/method: CDO. Domain interpretation: Data Owner **A**. Policy conflict: existing exception **A** (DMC) | No new A |
| Implemented | Evidence Register pointer; reporting pack update | DMO |
| Reviewed | Steward Forum / DMC pack as appropriate | Existing forums |
| Retired | KPI Change Record; executive set stays 10–15 | CDO; DMC **I** |

Swapping an executive KPI must keep the cover sheet **between 10 and 15** indicators.
