# Assets

Supporting materials for the Rafid Health Cluster Data Governance Framework.

| Folder | Contents | Use |
| --- | --- | --- |
| `diagrams/` | Conceptual diagrams (markdown / mermaid) | Phase structure, policy hierarchy, NDMO domain map |
| `tables/` | Reusable reference tables | Source labels; NDMO 15 domains |
| `templates/` | Document headers and labeling template | Consistency across later phases |
| [`practical-evidence/`](practical-evidence/) | Synthetic worked examples `[A]` | Quality, catalog, glossary, MDM, lineage — **not** operational evidence |

Do not store invented NDMO control catalogs here. Practical examples are **not** measured Rafid performance and **not** NDMO compliance.
