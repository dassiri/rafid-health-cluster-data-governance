# Source and assumption labels

Use these tags on every material statement.

| Label | Meaning |
| --- | --- |
| `[A]` | Fictional assumption — Rafid-specific fiction for the portfolio |
| `[B]` | Industry best practice — common governance practice, not an NDMO mandate |
| `[C]` | NDMO-supported — traced to official NDMO/SDAIA text (this repo: Standards v1.5, January 2021) |
| `[NDMO verification required]` | Not confirmed against official text for this use; must not be briefed as a requirement |

## Rules

1. Do not invent NDMO requirements.
2. Do not create fake NDMO control or specification numbers.
3. Do not claim compliance, certification, or completed audits.
4. Combine labels when a sentence mixes fiction and national text (for example `[A]` + `[C]`).
5. If an NDMO regulation is named but not retrieved, use `[NDMO verification required]`.
