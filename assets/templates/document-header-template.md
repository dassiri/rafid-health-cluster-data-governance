## ID convention (internal, not NDMO)

| Prefix | Meaning |
| --- | --- |
| `RHC-DG-P0-` | Phase 0 foundation |
| `RHC-DG-P1-` | Phase 1 direction |
| `RHC-DG-P2-` | Phase 2 design boundaries |
| `RHC-DG-DOC-` | Supporting docs (for example interview prep) |

Do not format these IDs to look like NDMO controls (`DG.1`, `DC.3`, and similar).
